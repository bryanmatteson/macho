# Generated ARM A64 codec

This private module contains the decoder and physical encoder generated by
[`mkasm` v0.2.0](https://github.com/bryanmatteson/mkasm/releases/tag/v0.2.0)
from Arm's A64 XML corpus (`ISA_A64_xml_A_profile-2026-06`).

The generated source is vendored so builds do not require Go, network access,
or the architecture corpus. Regenerate it with `scripts/generate-mkasm-codecs.sh`.
