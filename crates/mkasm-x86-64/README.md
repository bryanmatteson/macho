# Generated x86-64 codec

This crate contains the decoder and physical encoder generated by
[`mkasm` v0.1.0](https://github.com/bryanmatteson/mkasm/releases/tag/v0.1.0)
from the opcodesDB v3 x86-64 corpus.

The generated source is vendored so builds do not require Go or the architecture
corpus. Regenerate it with `scripts/generate-mkasm-codecs.sh`.
